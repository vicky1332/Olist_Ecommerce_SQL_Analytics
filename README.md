# Olist E-Commerce SQL Analytics

## Project Overview

An end-to-end SQL analytics project using the Olist Brazilian E-Commerce dataset to analyze sales, customers, sellers, products, payments, reviews, revenue, and delivery performance.

The project focuses on answering real-world business questions using MySQL and progressively applies advanced SQL techniques such as CTEs, subqueries, aggregations, and window functions.

## Business Areas

- Business Overview
- Sales & Revenue Analysis
- Order & Time Analysis
- Payment Analysis
- Customer Analysis
- Seller Analysis
- Review & Customer Satisfaction Analysis
- Freight & Delivery Analysis
- Delivery Performance Analysis
- Revenue Contribution Analysis
- Advanced SQL & Window Functions

## Dataset

The project uses the Olist Brazilian E-Commerce dataset, containing information about customers, orders, order items, products, sellers, payments, reviews, and related e-commerce operations.

## Project Goal

The goal of this project is to transform raw e-commerce data into meaningful business insights and demonstrate practical SQL skills through business-focused analytical problems.
